## Những gì đã cập nhật trong bản v1.1.1

### 1. Giao diện Floodlight toàn hệ thống
- Thiết kế lại toàn bộ 5 phân hệ theo hệ thống **Floodlight** ([DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md)):
  - **Trang chủ & Chi tiết trận đấu:** Khung khán đài navy ban đêm (`#0A1B30` / `#10253F`), danh sách trận đấu trên nền mặt sân sáng (`#F3F6FA`), tỷ số sử dụng font `Barlow Condensed` (`tabular-nums`), hổ phách (`#FFB020`) dành riêng cho Live và trận đang chọn.
  - **Trang giải đấu:** Hero banner navy, 9 tab gạch chân hổ phách, bảng xếp hạng & lịch thi đấu trên nền sáng, loại bỏ hậu tố ID thừa ở tiêu đề bảng.
  - **Trang Quản trị Admin & Đăng nhập:** Thanh điều hướng trái cố định khi cuộn, 4 thẻ KPI, bảng dữ liệu `.fl-table`, form cào dữ liệu 4 bước + thanh tiến trình trực tiếp, đồng bộ màu phân trang.
  - **Trang Tài liệu API (`/api/docs`):** Header Floodlight + Swagger UI tùy biến dễ đọc.
  - **Mission Control (`:8501`):** Giao diện phòng điều khiển navy, lưới 10 môn thể thao đồng đều chiều cao, bộ đếm thời gian thực & console log.
- Loại bỏ các nhãn cá cược **Tài / Xỉu** trong tab **Phân tích AI**, thay bằng số liệu thống kê thuần túy (*Phạt góc trung bình*, *Thẻ phạt trung bình*, *Trên 2.5 bàn*, *Trên 1.5 bàn*).

### 2. Bộ REST API v1 sẵn sàng cho Mobile App (Flutter / React Native / Android / iOS)
- Bổ sung [routes/api.php](../web/routes/api.php) (Stateless, Rate Limit `120 req/phút`, CORS tại [config/cors.php](../web/config/cors.php)).
- Endpoint dữ liệu 10 môn thể thao dùng chung cơ chế **DB-First**: `health`, `settings`, `sports`, `matches`, `matches/{sport}/{eventId}`, `extended`, `live`, `categories`, `leagues`, `competitions`.
- Hệ thống tài khoản App dùng **Bearer Token (SHA-256)**: `auth/register`, `auth/login`, `auth/me`, `auth/logout`.
- Tính năng **Yêu thích (`favorites/toggle`)** và lưu **Push Notification Device Token (`devices/register`)** cho Android/iOS/Web.
- Tài liệu tích hợp [API_APP_DOCS.md](../API_APP_DOCS.md), đặc tả OpenAPI 3.0 ([openapi.json](../web/public/openapi.json)) và Swagger UI (`/api/docs`).

### 3. Cấu hình thông tin trang web trong Admin
- Thêm bảng `site_settings` và mục **Cấu hình trang web** trong `/admin` cho phép chỉnh sửa trực tiếp: Tên trang web, Khẩu hiệu, Logo URL, Favicon URL, Môn mặc định, Mô tả SEO, Thông báo nổi đầu trang, Nội dung chân trang, Email liên hệ, Link hỗ trợ và Bật/Tắt Mission Control.
- Đồng bộ tức thì ra toàn bộ giao diện Web và endpoint `GET /api/v1/settings`.
